\section{Ownership Contract}

The ownership contract separates two kinds of process evidence. RLOG is about
records emitted by election systems or administrative processes. It can
normalize what a source log records and bind that normalization to source
bytes, parser transcripts, caveats, and optional RCOUNT identifiers. RCHAIN is
about physical custody records. It can normalize what a custody source records:
seals, transfers, observers, storage locations, retrieval sheets, and gaps.

Neither layer is allowed to convert count reconciliation into process proof.
The distinction is small but important. A reconciled count package can be an
input to a larger public evidence bundle, but it is not a custody record and it
is not an event log.
