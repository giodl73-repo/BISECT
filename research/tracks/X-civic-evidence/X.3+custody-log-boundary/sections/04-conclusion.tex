\section{Conclusion}

X.3 reserves RLOG and RCHAIN so that custody and event-log evidence have clear
owners when the project is ready for them. RLOG is reserved for normalized event
and status logs. RCHAIN is reserved for physical chain-of-custody records.
RCOUNT remains the owner of count reconciliation and must not claim physical
process facts that its evidence cannot prove.

Deferral is the right call now. The missing work is not code polish; it is
source pressure. The project still needs public examples of EMS logs, tabulator
logs, seal logs, custody forms, and observer records, followed by L0 fixtures
that force minimal schemas. Until that evidence exists, not implementing these
layers is the honest technical decision.
