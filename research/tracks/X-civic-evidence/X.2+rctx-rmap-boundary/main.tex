\begin{abstract}
The civic evidence package family needs a shared machine-context layer, but that
layer should not absorb every use of geography. This paper documents the X.2
boundary between RCTX and RMAP. RCTX owns canonical unit identity, context
hashes, graph identity, source hashes, aligned attributes, and exact rational
crosswalks. RMAP is reserved for rendered and cartographic presentation:
styling, layer composition, projections for display, tiles, images, and public
map hashes. The implemented surface is deliberately narrower than the concept.
The existing RPLAN \texttt{.rctx} implementation remains RCTX-compatible
phase-1 infrastructure, while \texttt{rctx-core} exposes the shared package,
crosswalk, graph-reference, source-reference, content-hash, and claim-boundary
checks needed by sibling products. A standalone RMAP crate and full
\texttt{rctx-io} loader remain deferred until a second production consumer
requires them.
\end{abstract}
