\section{Current Implementation Boundary}

The current U-track implementation family now includes exact-method substrates
(\texttt{bisect-ilp}, \texttt{bisect-column}), heuristic and frontier substrates
(\texttt{bisect-local-search}, \texttt{bisect-pareto},
\texttt{bisect-ensemble}, \texttt{bisect-multiscale}), and verifier-facing
RPLAN/RCTX packages.  Certification language should follow the artifact:
solver proof, bound report, heuristic diagnostic, selected-frontier package, or
final-plan audit certificate.

The implemented frontier now includes bounded exact split certificates,
recursive certificate trees, tree-to-RPLAN verification, hostile certificate
corpora, and deterministic pseudo-Boolean proof requests. Rhode Island's full
25,649-block connected RCTX is also available under local data custody.
RoundingSat and VeriPB proofs, scalable connectivity encoding, and a full
State optimality certificate remain open. U.21 defines this certified
recursive architecture in detail.

The key rule remains unchanged but is now more operational: never let a
heuristic diagnostic masquerade as a proof, and never let an audit certificate
for declared context become a claim that the plan is legally sufficient in the
world.
