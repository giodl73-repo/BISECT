\section{Conclusion}

W.05 defines a spatial-outlier method for the W-series: build a
shared-boundary neighbor graph over RCOUNT reporting units, compare each unit to
its local spatial baseline, record the statistic and caveats in the W.01 report
contract, and return an investigation queue. The useful signal is local
surprise, not proof.

The method is deliberately modest. It names established statistics, defines the
RCOUNT inputs they require, specifies the intended four-role fixture pattern,
and states the false-positive boundary. Implementation, fixtures, and any crate
placement remain downstream work. Until then, W.05 is a contract for how spatial
neighbor anomalies should be reported if they are added to the RCOUNT-adjacent
forensics track.
