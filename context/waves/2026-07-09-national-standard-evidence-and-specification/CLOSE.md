## Lessons

- Reproducibility failures are evidence and should be preserved.
- A hash manifest is insufficient unless the public acquisition path works.
- `git apply --check` does not prove every intended hunk was present; verify the
  changed file set and required content.
- Metric identity must travel with percentile claims.
- Input exclusion is not neutrality.
- Mathematics can remove post-enactment execution discretion only after
  contestable axioms are enacted.
