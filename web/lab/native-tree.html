Prepare a proof model from a context

The integer proof model requires positive integer edge weights. Fractional source weights are refused when kept. Choosing unweighted edge count explicitly creates a separate model with weights of one and retains the original context. Preparation does not discover a split or check a proof.

Generate a proof-carrying tree

Each node uses shared native discovery, checked decision proofs and native children derived from the proved parent. A counterexample or timeout stops generation without a complete certificate. Without a land source, the model graph is used for land adjacency.

A stopped split can be saved and opened in the individual split proof page. Its retained proof prefix is unverified and is not a complete tree certificate.
