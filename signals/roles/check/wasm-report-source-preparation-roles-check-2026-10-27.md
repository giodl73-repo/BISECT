This does not accept a State Run workflow, public UI, host permission behavior,
full field/parent parity, capacity matrix, release package or deployment.

Top finding: native report discovery must be connected independently of balancing
weights. BENCHMARK, COVENANT and LEDGER agree that successful preparation alone
cannot close accepted-output behavior.

Three required next amendments:
1. Bind report sources to actual compiled/accepted graph units and regenerate native
   context/provenance hashes without changing partition weights.
2. Connect explicit folder/file loading, original flags, source review and inert
   projects to the UI; restore no folder grant on Open.
3. Verify actual worker/Run/export/follow-up/project and final package outcomes on
   both builds, retaining native failure stages and broader unsupported rows.
