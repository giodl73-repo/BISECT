Top finding: preserve which explicit county mapping produced retained counts,
without treating its hash or a matching state code as source/legal authority.
COVENANT/VAULT agree on separate identities; CONTOUR/WARD/LEDGER agree on opaque
labels and withholding inferred compliance. BENCHMARK/MERIDIAN agree on actual
native references plus independently computed grouping expectations.

Three amendments assessed in the final artifact:

1. Separate explicit custom grouping from unchanged Census inference, with full
   identity coverage and ordered plan/context/CLI assignment checks.
2. Bind retained report counts to the effective county-map hash, while preserving
   native RPLAN/RCTX algorithms and testing valid-hash missing-data cases.
3. Version the custom response, update every supported browser consumer, and
   qualify support through actual CLI/browser/legacy/artifact evidence rather
   than declaration counts or a global parity claim.

Verified evidence: 33 shared Rust tests; eight native-host replies; five actual
CLI cases; eight refusals; three frozen legacy responses and optional previous
WASM replay passed locally; six independent Census report matches; combined
analysis-package regression; 40 native custom State workflow replies, three
browser-equal runs and independent ZIP/hash checks; source and packaged browser
tests; prior single/batch recovery regressions; asset/offline checks.
