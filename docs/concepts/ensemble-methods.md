# Ensemble Methods And Evidence Boundaries

## Short Version

An ensemble samples plans under one declared graph, population tolerance,
proposal kernel, initial plan, election model, and metric set. It does not
sample a universal set of "neutral plans."

The active real package is:

`docs/examples/g-ensemble-evidence-packages/G.1-G.3+real-2020/`

It compares the BISECT NRS v0.1 tract benchmark with Rust ReCom and independent
GerryChain 0.3.2 traces in Rhode Island, Iowa, and North Carolina.

## Current Result

| State | Rust cut percentile | GerryChain cut percentile | Primary limitation |
|---|---:|---:|---|
| Rhode Island | 1.35% | 1.81% | Two-district partisan metric is degenerate |
| Iowa | 0.33% | 0.88% | ESS 257/498 is too low for a sub-1% headline |
| North Carolina | 0.00% | 0.20% | ESS 109/87; tools differ materially |

These are percentiles of **unweighted tract-graph cut fraction**. They are not
Polsby--Popper, Reock, perimeter, or the shared-boundary-weight objective used
by the benchmark.

Wisconsin was selected in the preregistration but failed before sampling
because one benchmark district was disconnected. The failure remains part of
the evidence record; Iowa was added as the medium-state replacement.

## Experiment Contract

- Four chains per state and implementation.
- 2,000 steps per chain.
- First 500 steps discarded.
- 0.5% population tolerance.
- Partition snapshots every ten steps.
- Rust and GerryChain use random-weight Kruskal spanning trees for the
  cross-tool comparison.
- Benchmark and election inputs are hash-bound.
- RPLAN/RCTX baseline packages pass plan-shape, population, and contiguity
  audits for RI, IA, and NC.

The default `bisect-ensemble` chain continues to support Wilson uniform
spanning trees. The real comparison runner selects the GerryChain-compatible
kernel explicitly; the two kernels must not be described as the same stationary
distribution.

## Diagnostics

### R-hat

R-hat compares between-chain and within-chain variation. The project uses
`R-hat < 1.05` as a necessary scalar-convergence condition.

All reported cut-fraction R-hat values are below 1.05. This does not cure low
ESS or cross-tool disagreement.

### Effective Sample Size

The preregistration requires:

- ESS at least 100 for descriptive inference;
- ESS at least 1,000 before publishing a percentile below 1% or above 99%.

Rhode Island clears the tail threshold. Iowa and North Carolina do not.
North Carolina's GerryChain cut ESS is below 100.

### Partition-Space Mixing

Ten-step snapshot integrated autocorrelation times are approximately:

- Rhode Island: 21;
- Iowa: 11;
- North Carolina: 7--8.

Scalar diagnostics and partition diagnostics answer different questions and
must both be retained.

## Partisan Metrics

The primary election model uses the nationally consistent 2020 presidential
tract estimates:

| State | Benchmark D seats | Rust percentile | GerryChain percentile |
|---|---:|---:|---:|
| Rhode Island | 2 | 50.0% | 50.0% |
| Iowa | 1 | 36.7% | 33.9% |
| North Carolina | 5 | 17.1% | 21.2% |

Rhode Island's 50th percentile is a mid-rank artifact: all sampled plans have
two Democratic seats. North Carolina's seat ESS is below 100 in both tools, so
the values are non-converged descriptive estimates.

The locally available 2016 file does not align completely to 2020 tract
geography. It is archived with unmatched-unit counts but excluded from primary
partisan conclusions.

## Cross-Tool Comparison

Rust and GerryChain cut distributions differ:

- RI KS statistic: 0.038;
- IA: 0.162;
- NC: 0.471.

With autocorrelated samples, nominal KS p-values are not independent-draw legal
tests. The statistics are used as effect-size warnings that implementation and
proposal details affect the distribution.

## Evidence Package

The real package includes:

- frozen design and deviation log;
- Rust and GerryChain traces;
- aligned election arrays and source hashes;
- RPLAN and RCTX baselines;
- audit certificates;
- diagnostic and percentile analysis;
- software/input identity record;
- hash manifest; and
- a verifier that regenerates the analysis.

Run:

```powershell
python scripts\research\verify_real_ensemble_package.py `
  docs\examples\g-ensemble-evidence-packages\G.1-G.3+real-2020

cargo test -p bisect-ensemble real_g1_g3_package_validates
```

## What The Package Does Not Establish

- a universal neutral ensemble;
- national partisan fairness;
- polygon compactness percentiles;
- a global optimum;
- legal validity or VRA compliance;
- block-level NRS conformance;
- cross-election stability; or
- external peer review.

The earlier six-state 0.1--0.7th percentile and 61st--72nd Polsby--Popper
claims are withdrawn unless regenerated by a package with the required traces,
metrics, and diagnostics.
