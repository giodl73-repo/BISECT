# NRS v0.3 National Tier 2 Geometry Protocol

**Protocol ID:** `nrs-v0.3-national-tier2-geometry-v1`
**Status:** national execution complete; exact verifier published
**Date frozen:** 2026-08-08
**Owner:** BISECT research evidence layer

## Frame

The accepted Rhode Island Tier 2 slice demonstrates that NRS v0.3 and
official CD118 assignments can be dissolved from one retained-block universe
and measured under one geometry contract. That slice and the national Tier 1
packages remain authoritative for assignment projection and source identity.

The missing capability is a sequential national executor and exact verifier
that apply the accepted geometry contract to all 50 States without changing
the generator, comparator assignments, or metric definitions.

The falsifiable thesis is:

> The accepted common-block geometry method can produce complete, source-bound
> compactness descriptions for all 50 State plan pairs and all 435 districts,
> with every failure retained and the package exactly regenerable.

The thesis fails if any State source is missing or drifts, either plan loses a
retained block, district counts disagree, a dissolve or metric is invalid, the
national counts are incomplete, or exact regeneration differs.

## Frozen Universe And Execution

- Census year: 2020.
- Plan families: governed NRS v0.3 and official Census CD118 State archives.
- Atomic universe: each State's accepted Tier 1 `ALAND20 > 0` block universe.
- Assignment projection, source identity, numbered-district filtering, and
  water-only exclusion: unchanged from the Tier 1 protocol.
- Geometry, dissolve, perimeter, and metrics: unchanged from
  `nrs-v0.3-tier2-geometry-v1`.
- Execution order: State postal code ascending.
- Concurrency: exactly one State at a time.
- A State failure is recorded and execution continues. Failed States are not
  silently retried or excluded from the ledger.

## Outputs And Estimands

Each State package retains the accepted slice outputs. The national package
adds:

- `district-results.csv`: one row per measured district and plan family;
- `state-results.csv`: one row per State with both plan summaries;
- `analysis.json`: completeness, failures, national summaries, and claim
  boundary;
- `manifest.json`: hashes for all State outputs, national outputs, inputs, and
  code; and
- `README.md`: compact descriptive results and reproduction commands.

For each metric, report:

- district-weighted mean: arithmetic mean across all 435 districts;
- State-weighted mean: arithmetic mean of the 50 State plan means; and
- comparator-minus-NRS difference for each estimand.

No population-weighted compactness, national significance test, rank, winner,
or composite index is permitted. Per-State and per-district rows remain the
primary evidence because national means combine heterogeneous geographies.

The execution transcript reports elapsed seconds per State and total elapsed
seconds as operational diagnostics only. Timings are not hash-bound package
fields because clean regeneration must be byte-identical. Runtime does not
enter any quality metric.

## Acceptance And Verification

National status is `pass` only if:

- all 50 States pass;
- both plan families contain 435 districts;
- every accepted Tier 1 retained block is represented;
- every district metric is finite and in its frozen range;
- State and district ledgers exactly recompute `analysis.json`; and
- clean-tree regeneration is byte-identical.

The verifier runs sequentially and may not raise concurrency above one.

## Claim Boundary

This package supports descriptive national compactness summaries for 2020 NRS
v0.3 and official CD118 assignments after both are projected to identical
retained Census-block geometry. It does not measure original comparator
linework and cannot establish compactness superiority, fairness, intent, VRA
compliance, legal validity, community preservation, robustness, optimality,
causal effects, or adoption.
