# NRS v0.3 Rhode Island Sensitivity Protocol

**Protocol ID:** `nrs-v0.3-ri-sensitivity-v1`
**Status:** precommitted before diagnostic-seed generation
**Date frozen:** 2026-08-07
**Owner:** BISECT research evidence layer

## Frame

The governed Rhode Island NRS v0.3 package already provides the authoritative
two-district 2020 benchmark assignment. This experiment does not replace that
assignment or change the generator.

The missing evidence is the sensitivity schedule required by
`docs/legal/NRS_EVALUATION_SCHEDULE_V0.1.md`: 100 domain-separated diagnostic
seeds evaluated on the same block context and NRS v0.3 refinement path.

The falsifiable thesis is:

> The Rhode Island benchmark can be placed within a fully preserved
> 100-seed diagnostic distribution for assignment similarity, population
> deviation, and weighted boundary cut without promoting any diagnostic seed
> to the statutory benchmark.

The thesis is weakened by low benchmark agreement, frequent rejected seeds,
large objective dispersion, or a benchmark assignment that is atypical under
the frozen ranking. Every such result is retained.

## Seed Derivation

Diagnostic indices are the integers 1 through 100 inclusive. For index `i`:

1. parse the input manifest as JSON;
2. encode it as UTF-8 canonical JSON with keys sorted, separators `,` and `:`,
   and no trailing newline;
3. compute
   `SHA-256(ASCII("NRS_SENSITIVITY_V1") || 0x00 || canonical_manifest || uint32_be(i))`;
4. interpret the first eight digest bytes as an unsigned little-endian integer;
5. set `engine_seed = seed_u64 mod 2147483647`.

The diagnostic index, full digest, intermediate unsigned integer, and engine
seed are recorded. Duplicate engine seeds, if any, remain separate diagnostic
rows and are reported.

## Execution And Acceptance

Each seed runs:

```text
bisect exact
  --context <context>
  --districts 2
  --method certified-discovery
  --out-dir <temporary-seed-directory>
  --generated-at 2026-08-07T00:00:00Z
  --discovery-seed <engine_seed>
  --discovery-refinement nrs-v0-3
```

A seed is accepted only when the command exits zero and emits a
`certified-split-discovery-v1` artifact with:

- the benchmark instance hash;
- exactly 25,649 binary assignment labels;
- two nonempty districts; and
- the exact objective and connectivity validation performed by the command.

Failures retain the index, derivation, exit code, and final diagnostic line.
They are not rerun with replacement seeds.

## Frozen Metrics

District labels are permutation-invariant. For each accepted seed, assignment
agreement with the benchmark is the larger of direct and label-flipped block
agreement.

The package reports:

- accepted and rejected seed counts;
- duplicate engine-seed count;
- unique canonical-assignment count;
- exact benchmark-assignment reproduction count;
- per-seed matched blocks and matched-block rate;
- minimum, median, mean, and maximum matched-block rate;
- per-seed maximum and total scaled population deviation;
- per-seed weighted boundary cut;
- minimum, median, mean, and maximum for each objective component;
- benchmark rank under the existing lexicographic objective:
  maximum population deviation, total population deviation, weighted boundary,
  then canonical assignment; and
- the count satisfying the frozen NRS population tolerance. For Rhode
  Island's equal-seat root and published population `1,097,379`, the exact
  scaled bound is `(5 * 1 * 1,097,379 + 999) / 1,000 = 5,487`.

No diagnostic seed becomes a replacement benchmark, including the
lexicographically best seed.

## Evidence Package

The package contains:

- `analysis.json`: frozen summaries, benchmark placement, failures, and claim
  boundary;
- `seed-results.csv`: one row per diagnostic index;
- `assignments.bin`: accepted binary assignments packed little-bit-first, with
  offsets and lengths recorded in the CSV;
- `README.md`: human-readable result and exact commands; and
- `manifest.json`: input, executable, code, and output hashes plus the
  reproduction contract.

The verifier independently checks seed derivation, packed assignments,
per-seed metrics, national-package input hashes, and exact package
regeneration. Regeneration must preserve all failed seeds rather than silently
dropping them.

## Claim Boundary

This is a Rhode Island root sensitivity diagnostic on one Census vintage. It
does not establish national robustness, ensemble convergence, random sampling,
partisan fairness, compactness superiority, VRA compliance, legal validity,
optimality, or permission to replace the governed benchmark.
