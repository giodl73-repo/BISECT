# NRS v0.3 Tier 2 Geometry Protocol

**Protocol ID:** `nrs-v0.3-tier2-geometry-v1`
**Status:** frozen before result generation
**Date frozen:** 2026-08-08
**Owner:** BISECT research evidence layer

## Frame

The governed Tier 1 bakeoff already projects NRS v0.3 and the official CD118
comparator onto one complete 2020 block universe. It remains authoritative for
source identity, district assignment, and block inclusion.

The missing shared capability is a source-bound geometry layer that dissolves
that same block universe by plan assignment and computes identical descriptive
shape metrics for both plan families. NRS generation and the comparator remain
unchanged and owner-controlled.

The falsifiable first-slice thesis is:

> Rhode Island's two plan families can be reconstructed from the same retained
> block geometries and measured with one frozen projection, perimeter rule, and
> metric implementation, with exact package regeneration.

The thesis fails if either plan does not cover every retained block exactly
once, a district dissolve is empty or invalid, district counts differ from
Tier 1, metric identities fail, or exact regeneration differs.

## Geometry And Perimeter Contract

1. Read each retained block geometry once and project it to `EPSG:32130`.
2. Require every projected block geometry to be nonempty and valid.
3. Join the complete retained-block table separately to the NRS and comparator
   assignments.
4. Dissolve complete block polygons by district with GEOS unary union.
5. Require exactly two nonempty, valid district geometries for each plan.
6. Use the complete dissolved geometry, including disconnected components and
   interior-ring boundaries. No smoothing, simplification, hole removal,
   coastline replacement, or geometry repair is permitted.
7. Area is planar dissolved-geometry area. Perimeter is planar
   dissolved-geometry boundary length. Because both plans use the same
   retained-block polygons, external coast and excluded-water interfaces enter
   under the same rule.

This is block-projected geometry, not a measurement of the original enacted
polygon linework.

## Metrics

For each district:

- Polsby--Popper: `4 * pi * area / perimeter^2`;
- exact Reock: `area / (pi * minimum_bounding_radius^2)` using GEOS
  `MinimumBoundingCircle`;
- convex-hull ratio: `area / convex_hull_area`; and
- Schwartzberg: `perimeter / (2 * sqrt(pi * area))`.

The analyzer must require positive finite area, perimeter, bounding radius, and
hull area; scores must be finite and within their mathematical ranges.
Schwartzberg must agree with `1 / sqrt(Polsby--Popper)` within `1e-12`.

The package reports per-district values and unweighted two-district means for
each plan. Comparator-minus-NRS differences are descriptive only. It emits no
winner, rank, significance test, or composite score.

## Evidence And Failure Contract

The package contains:

- `analysis.json` with per-district metrics, plan summaries, diagnostics,
  unavailable metrics, and the claim boundary;
- `manifest.json` binding protocol, analyzer, verifier, assignments, geometry,
  and generated outputs; and
- `README.md` with the compact result and reproduction commands.

Tests must cover at least:

- known square metric identities;
- a multipart geometry;
- invalid or empty geometry rejection; and
- assignment-universe mismatch rejection.

The verifier re-hashes all inputs and code, regenerates the package in a
temporary directory, and requires byte-identical outputs.

## National Expansion Gate

No national Tier 2 execution occurs until the Rhode Island package and its
structured failures pass. A later national protocol must freeze State-specific
equal-area projections, State-weighted and district-weighted summaries,
failure retention, and runtime limits before execution.
