# NRS v0.3 NH/NM/GA Block-Ensemble Expansion

**Protocol ID:** `nrs-v0.3-block-ensemble-expansion-v1`

**Frozen:** 2026-08-10, before any NH, NM, or GA governed block chain

**Status:** frozen; Stage 0 implementation and excluded preflight required

## Question

Do the Wilson and random-weight Kruskal kernels complete reproducible,
diagnostically reportable block-graph ReCom chains on the precommitted NH, NM,
and GA 2020 NRS v0.3 starting plans within the resource budget derived before
this protocol was frozen?

This is a three-State feasibility and kernel-sensitivity expansion. It is not
a national ensemble, sampler-equivalence test, mixing proof, fairness test, or
legal-validity study.

## Frozen Inputs And Schedule

| State | Blocks | Districts | Starting max deviation |
|---|---:|---:|---:|
| NH | 31,948 | 2 | 0.000007985312831889564 |
| NM | 107,215 | 3 | 0.000010861752557887751 |
| GA | 232,717 | 14 | 0.0029925574416808346 |

Each State uses its certified 2020 block RCTX and governed NRS v0.3
`baseline_assignments.json`, already hash-bound by the Pulse 24 input audits.
Population tolerance is `0.005`. The primary kernel is Wilson uniform spanning
tree; the sensitivity kernel is GerryChain-compatible random-weight Kruskal.

For every State and kernel run four chains, 2,000 steps per chain, discard the
first 500 steps, snapshot every 10 steps, and use base seed `20260810` with
`bisect_ensemble::chain::chain_seed`. Execute exactly in this order:

1. NH Wilson, then NH Kruskal;
2. NM Wilson, then NM Kruskal; and
3. GA Wilson, then GA Kruskal.

Only one runner process and one chain may be active. No failed or
non-converged chain may be replaced, extended, or rerun under changed
parameters. A valid non-converged result is retained as negative evidence.

## Resource Contract

Pulse 24 measured Rhode Island OS peak RSS and wall time before this protocol
was frozen and mechanically authorized:

- total primary plus exact-replay wall budget: 21 hours;
- per-process peak RSS: 2,415,919,104 bytes (2.25 GiB);
- retained evidence: 3 GiB; and
- scratch evidence: 3 GiB.

An external monitor must sample at 50 ms or faster and enforce these ceilings.
Exceeding any ceiling terminates the active process, retains a failure record,
and closes the expansion without retry. Wall time is cumulative across all six
primary runs and six exact replays. Scratch traces are deleted only after exact
normalized comparison. Release builds, analysis, hashing, and input audits are
reported separately from the 21-hour runner wall budget.

## Stage 0

Before a governed chain:

1. extend the runner's governed guard to accept only the exact State-specific
   district count and the frozen common chain parameters;
2. extend the resource monitor to enforce cumulative wall, memory, retained,
   and scratch ceilings;
3. verify all three existing input audits against source custody;
4. run one excluded 25-step chain per State and kernel in the frozen order;
5. retain timing, peak RSS, acceptance, population, and normalized replay
   diagnostics from preflight; and
6. abort before governed execution if projected remaining work no longer fits
   the frozen ceilings.

Preflight samples are barred from governed analysis and stopping decisions.

## Diagnostics

Analyze each State and kernel separately using the Rhode Island Stage 1
implementations and thresholds:

- split-chain R-hat for cut fraction and weighted boundary cut;
- per-chain and pooled ESS for both metrics;
- acceptance and maximum population deviation;
- label-aligned Hamming-distance diagnostics from snapshots; and
- cross-kernel means, standard deviations, quantiles, and descriptive KS.

A kernel is labeled converged only when both scalar metrics have split-R-hat
below 1.05 and pooled ESS at least 100. Tail statements outside 1--99 percent
require relevant ESS at least 1,000. Passing does not prove mixing or
independence. Kernels and States may not be pooled.

## Verification And Decision

The expansion gate passes only if all 24 primary chains complete, every
recorded plan remains contiguous and inside tolerance, analysis recomputes,
resource ceilings hold, package verification passes, and a fresh execution in
the same State/kernel order regenerates normalized metrics and canonical
snapshots exactly for all six traces.

Stop after these three States. No adaptive State selection, seed retry, chain
extension, additional election, or national expansion is authorized.

## Claim Boundary

The completed package may support only 2020 NH/NM/GA block-graph feasibility,
registered scalar diagnostics, and State-specific kernel sensitivity under the
frozen starts and seeds. It cannot establish national representativeness,
neutrality, partisan or demographic fairness, VRA compliance, legal validity,
polygon compactness, sampler equivalence, portable performance, or coverage of
all valid plans.
