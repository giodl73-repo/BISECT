# Bound State name execution workflow — selected-source scope

Date: 2026-10-27. This continues the
[native identity work](wasm-native-state-identity.md). The direct prepared compiler
still refuses all 14 orchestration fields. An explicit browser workflow now maps
`--state-name` after fresh native inspection and source binding; it does not remove
the compiler's guard or establish full parent acceptance.

## Behavior

Inspect retains the native adjacency-only override, raw effective name, generated
or explicit label, native year preflight and proposed relative writer namespace.
Apply binds those observations to the exact original command and selected
adjacency preparation plus auxiliary-source identity. It removes the mapped name
from engine-only flags and applies the native export label. Registered state/year/
chamber scope cannot silently move to another source or national job.

Before Run, fresh native inspection reconstructs the entire binding. Changed
source bytes, auxiliary bundle, label, policy metadata or flags refuse before
preparation/partition. The original flags and exact unsigned seed remain retained.
Review original flags again restores the original command for explicit
reinspection and reapplication; it does not run or grant folder access.

Accepted selected-binary runs prepare the correct native state-name or explicit
label namespace. Internal spaces and raw case remain distinct from the normalized
default label. Output aliases and manifest adjacency basename/hash follow the
bound name. The manifest update stays inside typed Rust serialization, preserving
`u64::MAX` in the actual JSON text. The report remains research metadata from
supplied sources; no native-executable or authenticated Census provenance is
invented.

Selected auxiliary JSON is an explicit source-role association, hashed with its
original name/text. Native generated basename intents are retained separately.
This does not automatically discover or load the named demographic, VAP/CVAP,
LODES or housing files. Those source mechanisms and original bytes must not be
silently substituted or inferred from the name.

## Targets and custody

Installation and Force/reset use the original named command in the shared native
target inspector. Existing incomplete markers still block forced actions. A live
folder review and fresh source-bound callback are required before reset; a stored
receipt is not authority. Reset removes only data/, preserving existing RPLAN and
manifest files until a separate installation. Stale target observations and
consumed reviews refuse before further effects. Guard reinspection also refuses
changed policy/name interpretation at installation.

Output components remain bounded portable ASCII names, with internal spaces
allowed. Unsafe effective names refuse without sanitization; an unsafe requested
name ignored by the native non-adjacency branch remains inert data. Unicode names
can be inspected but this output workflow does not yet support Unicode components.
The recorded native output path is intent. The selected browser outputs parent
and explicit version establish the actual installation namespace.
