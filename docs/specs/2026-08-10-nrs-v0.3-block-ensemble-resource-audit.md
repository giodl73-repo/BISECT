# NRS v0.3 Block-Ensemble Resource Audit

**Protocol ID:** `nrs-v0.3-block-ensemble-resource-audit-v1`

**Frozen:** 2026-08-10, before instrumented resource execution

**Status:** frozen; implementation and excluded resource replay required

## Purpose

Measure process peak resident memory, wall time, and trace size for the already
frozen Rhode Island block-level Stage 1 execution so a later NH/NM/GA expansion
protocol can state explicit resource budgets. This audit does not add ensemble
draws, change diagnostics, or authorize an expansion by itself.

## Frozen Execution

Run the same release executable, input hashes, Wilson-then-Kruskal order, four
chains, 2,000 steps, `0.005` tolerance, base seed `20260810`, and snapshot
stride `10` used by `nrs-v0.3-block-ensemble-gate-v1`. Only one runner process
may be active. Each resource trace must regenerate the committed normalized
metrics and canonical snapshots exactly, after which the scratch trace is
deleted.

The wrapper must use `psutil` and poll at 50 ms or faster. On platforms that
expose an operating-system process peak working set, retain that value. Also
retain the maximum sampled resident set, sample count, polling interval, wall
time, executable/source/input hashes, raw scratch-trace size and SHA-256,
normalized trace SHA-256, acceptance rate, maximum population deviation, and
mean recorded step runtime. Child-process memory must be included if any child
exists.

These runs are labeled `excluded-resource-replay`. They may not enter an
ensemble percentile, convergence calculation, tail claim, or stopping
decision. Runtime fields remain diagnostic and are excluded from deterministic
trace comparison.

## Candidate Expansion Cohort

The only cohort considered by the subsequent decision is NH, NM, and GA 2020.
The input adapter must audit each State before any expansion protocol is
frozen. State selection was declared by the Stage 1 gate and may not change in
response to observed Rhode Island results.

Let `r_s = U_s / U_RI`, where `U_s` is the audited block count. Let `W` be the
sum of measured Rhode Island Wilson and Kruskal wall times, `M` the larger
measured kernel peak RSS, and `B` the sum of their trace sizes.

If the resource audit passes, calculate budgets mechanically:

- projected compute: `sum(r_s) * W`;
- authorized compute budget: twice projected compute, rounded up to a whole
  hour, with a hard ceiling of 48 wall-hours;
- projected peak resident memory: `max(r_s) * M`;
- authorized per-process memory: 1.5 times projected peak, rounded up to the
  next 256 MiB, with a hard ceiling of 4 GiB;
- projected retained trace storage: `sum(r_s) * B`;
- authorized retained storage: twice projected storage, rounded up to a whole
  GiB, with a hard ceiling of 8 GiB; and
- scratch storage authorization equal to the retained-storage authorization.

Exceeding any hard ceiling closes the expansion gate. Passing the formulas
permits drafting, but not executing, a separately frozen NH/NM/GA protocol.

## Evidence And Verification

Retain the protocol, wrapper source and tests, one measurement JSON per kernel,
a summary with formula inputs and outputs, deviations, manifest, and verifier.
The verifier must re-hash all retained inputs, validate both measurement
schemas, confirm exact normalized-match status, recompute the budget formulas,
and reject any claim that the resource replays are statistical samples.

## Claim Boundary

This audit can support only author-machine resource planning for a later
sequential NH/NM/GA block-ensemble protocol. It does not establish portable
performance, mixing, independence, sampler equivalence, national
representativeness, neutrality, fairness, legal validity, or permission to run
the expansion before a new protocol is frozen.
