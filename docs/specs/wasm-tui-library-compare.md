# Plan library assignment handoff

Selecting a freshly inspected plan in the browser's native plan library and opening Compare now retains its exact `data/final_assignments.json` alongside the four supported analysis files. The handoff preserves the existing Plan B and performs no engine operation. Explicit Compare uses the shared native TUI comparator.

Previously, the library recorded only summaries and presence-only artifacts. The Compare shortcut copied summaries but omitted the assignment map, so the native comparator used its missing-assignment default even when the selected folder contained assignments. The regression fixture has three assignment keys, including a maximum u64 district value. Its actual native score is 1/3; dropping the Plan A assignment source produces 0. This fixture checks the native comparison's matching semantics, not the validity of those district identifiers as a certified plan.

Assignment bytes remain opaque UTF-8 through folder reading, handoff and Save/Open. JavaScript does not round u64 assignment values. Native library inspection still receives the same manifest/analysis request; assignment interpretation happens only during explicit comparison. Comparison sources are copied so edits cannot mutate the retained library. Older library projects without assignment sources remain valid. The Compare panel states whether an assignment source is retained or absent; missing/malformed input still follows the native comparator's disclosed defaults.

The existing 100-folder and 16 MiB total library limits remain. Summaries retain their 1 MiB limit; assignment JSON uses the existing Compare limit of 8 MiB per source. File sizes and total bytes are checked before reading bodies. Duplicate paths, invalid UTF-8 and changing byte lengths are rejected. Maps, audit files and RPLAN files remain presence-only in this library flow. Selecting a folder with assignments beyond these bounds is an explicit refusal, not proof of full-state or national capacity.

`test_tui_library_compare.mjs` checks an actual native directory comparison, exact source retention, immutable handoff, legacy projects, empty sources and pre-read/UTF-8/duplicate guards. `test_tui_library_compare_browser.mjs` uses real folder selection and WASM workers, verifies the inert handoff and native score, retains Plan B, and checks Save/Open with retired imported exports and a 390px viewport. Existing 40 native library discovery/sort/filter cases, 36 native comparison cases and the project UI regression also pass. No deployment or complete practitioner/TUI parity claim is made.
