# Native Run source queue

The browser can apply inspected native `Run` flags to queued original tract sources, then explicitly execute the native congressional queue. This complements graph/template execution; it does not replace the native Run compiler or introduce algorithm defaults in JavaScript.

1. Queue native binary or Census tract sources with export metadata.
2. Select **Inspect native Run flags**, enter the actual argument vector, and inspect it.
3. Choose **Apply inspected Run flags to source queue**. This preserves original bytes, auxiliary inputs and follow-up settings, records new recipe hashes, selects the embedded allocation and adopts the command's state/year policy. It performs no preparation or partition.
4. Explicitly run the queue. `--year all` schedules 2020, 2010 and 2000 in native order. Every year uses the same WASM artifact. Native worker requests are capped by available CPU slots and selected states; zero requests automatic sizing.
5. Save the project or download the output archive. Open remains inert. Saved outputs need explicit native replay verification before exports become active; session Resume retains verified completed outputs and retries unfinished work.

The master flags must agree with each original source recipe and hash before preparation. Raw state filters remain in the native command review, including non-code strings; adapting them to manifest selection must never turn an unmatched filter into all states. Run filters must include the selected source; they are not rewritten to force eligibility. Print-only prevents preparation and partitioning. A failed year is recorded and later years continue.

Source acquisition/streaming accepts native Run flags, checks vintage/filter/output-version policy before downloads, and saves original sources with accepted outputs. With an all-vintage Fetch plan and native Run source mode, the explicit streaming button schedules 2020, 2010 and 2000. Each vintage gets a separate output folder under a fresh run folder. Missing pairs produce failed-year receipts without acquisition for that year. The native manifest and browser acquisition catalog now include all 50 states for 2000 as well as 2010 and 2020. Missing or unavailable pairs still produce explicit failures. The 2000 population source is the original PL94 geography ZIP (`*geo.upl.zip`), whose geography records already carry the POP100 values consumed by the native parser; no population segment is needed.

The streaming parent pins a single WASM artifact across years, awaits parent checkpoint writes, checks their bytes after close, and stops on cancellation or artifact changes. Ordinary year failures preserve outputs and allow later years to continue. Native installation failures remain separate from accepted partitions and make the year unsuccessful. Reopening a project does not read the saved directory or resume streaming automatically. Native output paths are retained as intent; browser directory access remains explicit. Native flags that the desktop Run branch does not consume do not silently trigger browser follow-up work.

Validation uses synthetic four-unit binary VT/WY source fixtures across three vintages: six primary Runs, 178 complete native-host/WASM reply comparisons, single-year and multi-year Resume, saved full replay, metadata/source tampering refusals, worker caps/zero-auto, unmatched filters and failed-year continuation. Real Chrome workers verify inspect/apply/Run, Save/Open, saved replay, output-version handoff, inert detach and a 390px viewport. Python independently checks both Node and browser nested ZIPs, source/request hashes, exact plans/contexts and native assignment indices. A separate single-year Census stream test covers WY/VT, 40 whole native-host replies, filtering, cancellation, saved original-source projects and refusals before acquisition. These small cases establish wiring and integrity, not national capacity or every algorithm/source combination.

Tests: `test_native_run_queue.mjs`, `test_native_run_queue_browser.mjs`, `test_native_run_queue_zip.py`, and `test_stream_native_run.mjs` under `scripts/web/`. Generate Node fixtures before running the corresponding browser tests. No deployment is part of this increment.

The streaming parent is covered by `test_stream_native_run_years.mjs` (complete native-host/WASM reply comparisons), `test_stream_native_run_years_browser.mjs` (real Chrome workers and OPFS) and `test_stream_native_run_years_files.py` (independent original-ZIP, nested output, hash and installation checks). The fixtures use two synthetic VT tracts in each supported acquisition vintage. Tests cover three successful vintages and separately remove the 2000 pair to verify the failed-year receipt without acquisition for that year. They also verify failed-year continuation, cancellation, artifact changes, output-version mismatch and corrupt checkpoint readback. This does not establish nationwide original-data capacity.

The 2000 endpoints were verified against the Census [tract directory](https://www2.census.gov/geo/tiger/TIGER2010/TRACT/2000/) and each state's directory under the original [PL94 archive](https://www2.census.gov/census_2000/datasets/redistricting_file--pl_94-171/). `verify_census_2000_sources.py` retains those listings and hashes; `--download-state VT` explicitly downloads the original two ZIPs. The downloaded Vermont geography is byte-identical to the repository's retained native geography, with 24,824 blocks and population 608,827. SF1 was not substituted for PL94.

For the original-data check, run `test_census_2000_acquisition.mjs --original` followed by `test_census_2000_original.py`. The optional browser check `test_stream_native_run_years_browser.mjs --original-2000` substitutes only the 2000 fixture with original VT archives, while 2020/2010 remain synthetic; verify its files with `test_stream_native_run_years_files.py --original-browser-2000`. These are bounded original-state checks, not evidence that every state's original three-vintage workload fits browser memory. The added 2000 build gates use small offline fixtures and never implicitly download Census data.
