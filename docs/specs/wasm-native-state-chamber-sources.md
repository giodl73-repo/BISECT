# Native chamber support for selected State sources

Single selected-source State Runs now accept congressional, House and Senate metadata for known Census states. The source recipe records `source_scope_policy: match-native-flags`. Execution inspects the original State flags and requires matching state, year, resolution, chamber and district count. It passes those flags unchanged to the native compiler; it no longer calls the congressional queue's scope-rewriting operation. Explicit counts remain explicit, and absent counts/tolerances are resolved by the existing native chamber policy.

The national source queue remains congressional. Its UI queue action is disabled for legislative source metadata, and queue validation rejects House/Senate jobs. Selecting a single State Run is explicit and inert. Applying a native Run/States master policy to an eligible congressional source explicitly retires its single-source scope policy while preserving the original unmodified job. The existing State-only workflow-binding restrictions still apply.

Selected native binary, Census and tract source inputs support these chambers through the shared source/preparation/compiler/retry/export path. `--adjacency` can bind House/Senate selected binary sources, retaining the exact binary/companions and original path intent. Export metadata must match the flags. The native-file default-flags action carries the chosen chamber. Accepted RPLAN metadata and source recipes retain it. Prepared-state execution validates matching metadata and accepts the three native chambers; the separate national batch validator still enforces its congressional policy.

The visible command review now shows resolved district count and provenance as well as the exact seed. Source workbench archives reopen in single-state mode with their source kind, chamber, original flags, optional binding and selected files intact, without execution. The actual workbench archive reader is exercised; these archives use the `.bisect-workbench` format. House mapping and labeled research output use the accepted plan without a second partition.
