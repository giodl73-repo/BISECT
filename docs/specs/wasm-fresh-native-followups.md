# Fresh State follow-ups

After a current fresh State Review and Run, **Use for audit**, **Use for analysis**
and **Use for improvement** select the exact completed native RPLAN and RCTX in
the workbench. Selection performs no computation. Choose any required profile
and additional sources, then press Execute explicitly.

The handoff checks the ordered executed unit universe, complete one-based engine
assignments against the zero-based plan, native scope, text/object correspondence
and current input/context binding. It preserves the native unit kind, including
Imported fallback cases, rather than converting it to a Census kind. Existing
certificates and lineage are detached. Improvement initially uses the completed
request's population tolerance; existing unrelated source inputs stay selected.

These consistency checks do not authenticate an imported record. The panel's
live review/run grant controls the buttons. Edits retire that grant. Project,
archive and autosave restoration preserve saved data without enabling follow-up
buttons; viewing an unverified saved run cannot enable them. Loading or selecting
outputs never issues a certificate or claims that the plan passes an audit.
