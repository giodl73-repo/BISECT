## Compiled-Runner Contract Gate

Before the package can be declared ready, the exact release executable that
will run v3 must be invoked with `--contract-only true` for every State and
sampler under both frozen shapes:

- `excluded-expansion-v3-preflight`, 25 steps, one chain; and
- `governed-stage2-v3`, 2,000 steps, four chains.

Each of the 12 probes must accept year 2020, tolerance 0.005, base seed
20260812, snapshot stride 10, the State's frozen district count, and the named
sampler. The probe must return zero before resolving RCTX or assignment paths,
creating an output directory, or writing a trace. Readiness records the exact
argv, return code, stdout, stderr, and executable SHA-256 for every probe.

Readiness fails if any probe rejects, if a wrong seed or predecessor execution
class is accepted as v3, if the executable hash changes after probing, or if a
probe creates a package artifact. Source inspection or a Python command-unit
test cannot substitute for these compiled probes.

## Resource And Execution Gates

The frozen ceilings remain 21 cumulative governed runner hours, 2,415,919,104
bytes peak RSS per process, 3 GiB retained evidence, 3 GiB replay scratch, and
2 GiB host safety reserve. With empty custody, each launch requires at least
8 GiB free. A fresh, unique capacity-admission record is required immediately
before every preflight, primary, and replay process.

After compiled-contract readiness is committed and reviewed, Stage 0 requires
one excluded 25-step preflight per State and kernel in frozen order, followed
by fresh-process exact normalized replay of all six. Stage 0 samples are barred
from governed analysis. No governed process may begin until Stage 0 passes.

Once a runner process begins, any nonzero exit, ceiling breach, invalid trace,
schedule violation, or replay mismatch closes v3 without retry. Prelaunch
capacity rejection creates no process and may be rechecked only after removing
independently disposable data. A valid non-converged governed result is retained
as negative evidence and cannot be replaced or extended.

## Diagnostics And Decision

For each State and kernel separately, compute split-chain R-hat and per-chain
and pooled ESS for cut fraction and weighted boundary cut, acceptance, maximum
population deviation, label-aligned snapshot Hamming distance, descriptive
quantiles, and cross-kernel KS. Convergence requires both scalar R-hat values
below 1.05 and pooled ESS at least 100. Tail statements outside 1--99 percent
require relevant ESS at least 1,000. States and kernels may not be pooled.

The gate passes only if all 24 primary chains complete, every recorded plan is
contiguous and within tolerance, all resource and admission records verify,
analysis recomputes, and all six governed replays regenerate normalized metrics
and canonical snapshots exactly. Otherwise v3 fails and closes.

## Custody And Claim Boundary

The package binds the protocol, wrapper, verifier, input audits, runner source,
release executable, compiled-contract probe record, ledger, admission records,
resource records, traces, analysis, and manifest by SHA-256. V1 and v2 are
preserved only by immutable reference and cannot appear as v3 completions.

A passing package can support only bounded 2020 NH/NM/GA block-graph
feasibility, registered scalar diagnostics, deterministic replay, and
State-specific Wilson-versus-Kruskal sensitivity under the frozen starts and
v3 seeds. It cannot establish national representativeness, mixing, sampler
equivalence, neutrality, partisan or demographic fairness, VRA compliance,
legal validity, polygon compactness, or coverage of all valid plans.
