# NRS v0.3 Initial DFS Tie Census Protocol

**Protocol ID:** `nrs-v0.3-initial-dfs-tie-census-v1`
**Status:** precommitted before the instrumented national root census
**Date frozen:** 2026-08-07
**Owner:** BISECT reference-engine and research evidence layers

## Frame

Four governed sensitivity slices covering 400 diagnostic runs reproduced their
benchmark roots exactly. Source inspection shows that the NRS v0.3 discovery
seed can affect the initial deterministic DFS candidate only when multiple
candidates tie first on population deviation and then on weighted boundary
cut.

The missing capability is direct observability of that pre-seed tie
multiplicity. The governed assignments remain authoritative.

The falsifiable thesis is:

> Behavior-preserving instrumentation can identify which governed 2020 State
> roots, if any, expose more than one minimum-deviation/minimum-cut initial DFS
> candidate and therefore warrant further seed execution.

The thesis fails if instrumentation changes any governed assignment or
objective, if the counters are not deterministic, or if a root cannot be
replayed from its committed context and benchmark seed.

## Instrumentation Contract

`nrs_dfs_tree_cut_candidate` returns the selected assignment plus:

- `minimum_deviation_candidate_count`: subtree/complement candidates tied at
  the minimum scaled population deviation; and
- `minimum_deviation_cut_candidate_count`: those candidates also tied at the
  minimum weighted boundary cut.

The existing selection key remains exactly:

1. weighted boundary cut;
2. population moved relative to the seeded METIS assignment; and
3. minimum unit index.

The new values are appended to the discovery method string as:

- `initial-dfs-minimum-deviation-candidates=<n>`; and
- `initial-dfs-minimum-deviation-cut-candidates=<n>`.

A root has an initial seed-sensitive tie opportunity only when the second
counter exceeds one. This identifies opportunity, not proof that two seeds
produce different final assignments after population refinement or fallback.

## Frozen Census

- Census year: 2020.
- Universe: all 44 governed multi-district State roots.
- Context: each committed `data/2020/certified/<state>_blocks_2020.rctx`.
- District count and benchmark seed: each committed root `baseline-tree.json`.
- Benchmark assignment and objective: each committed root
  `certified-discovery.json`.
- Refinement: `nrs-v0-3`.
- One instrumented replay per State using its published benchmark seed.

One-district States are excluded because they have no root split.

## Acceptance And Metrics

Every State must:

- exit zero;
- preserve the governed canonical assignment exactly;
- preserve all three governed objective components exactly;
- emit positive minimum-deviation and minimum-cut candidate counts; and
- satisfy `minimum_cut_count <= minimum_deviation_count`.

The package reports every State row, failures, count distributions, and the
States with `minimum_cut_count > 1`. States are never replaced after outcomes.

## Claim Boundary

This census observes only the initial root-0 DFS candidate stage. It does not
instrument alternate-root v0.2 fallback candidates, v0.3 bridge-aware fallback,
child nodes, final seed sensitivity, national robustness, optimality, or legal
quality.
