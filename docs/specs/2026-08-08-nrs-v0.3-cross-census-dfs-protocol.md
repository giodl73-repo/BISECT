# NRS v0.3 Cross-Census Complete-Tree DFS Protocol

**Protocol ID:** `nrs-v0.3-cross-census-complete-tree-dfs-v1`
**Status:** precommitted before the 2000/2010 instrumented replay
**Date frozen:** 2026-08-08
**Owner:** BISECT reference-engine and research evidence layers

## Frame

The governed 2020 complete-tree replay found one physical initial DFS cut at
all 385 nodes and no fallback activation. That result does not cover the
different source geography and documented amendment witnesses in 2010 and
2000.

The governed history already records a 2010 California v0.1 tolerance miss
resolved by the v0.2 alternate-root fallback and a 2000 Hawaii v0.2 tolerance
miss resolved by the v0.3 bridge-aware fallback. The missing evidence is a
uniform node ledger showing every activation and initial-cut multiplicity
across both complete trees.

The falsifiable thesis is:

> The existing behavior-preserving diagnostics can exactly regenerate the
> governed 2000 and 2010 trees, enumerate all fallback activations, and
> distinguish those amendment witnesses from ordinary nodes.

The thesis fails if any State assignment or node objective changes, either
385-node universe is incomplete, or activation fields do not preserve the
documented witnesses.

## Frozen Census

- Census years: 2000 and 2010.
- Universe: all 770 governed recursive split nodes, 385 per year.
- Multi-district States: 43 per year.
- Inputs: committed year-specific RCTX files, seed packages, benchmark trees,
  and benchmark node discoveries.
- Replay: rebuild every multi-district State package with its published seed
  package and the instrumented executable.
- Acceptance: exact State assignment preservation and exact per-node canonical
  assignment plus all three objective-component preservation.

The package reports year, State, node path, seat ratio, unit count, oriented
and unlabeled initial DFS counts, fallback activation, and preservation.

## Decision Rule

- Any node with multiple unlabeled initial DFS partitions permits a separately
  precommitted seed slice.
- Every activated fallback node advances to stage-specific candidate
  multiplicity instrumentation before seed execution.
- Nonactivated nodes do not enter fallback sensitivity work.

## Claim Boundary

This is a complete-tree diagnostic replay for governed 2000 and 2010
baselines. It does not establish seed-invariant labels or plans, national
robustness, optimality, partisan properties, legal quality, or cross-decade
assignment overlap.
