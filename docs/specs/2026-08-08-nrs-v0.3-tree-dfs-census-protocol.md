# NRS v0.3 Complete-Tree DFS Census Protocol

**Protocol ID:** `nrs-v0.3-complete-tree-dfs-census-v1`
**Status:** precommitted before fallback instrumentation and execution
**Date frozen:** 2026-08-08
**Owner:** BISECT reference-engine and research evidence layers

## Frame

The 44-State root census found one physical
minimum-deviation/minimum-cut initial DFS bipartition in every governed root.
The published national 2020 baseline contains 385 recursive split nodes, while
the prior census observed only the 44 root nodes and did not report whether
the v0.2 alternate-root or v0.3 bridge-aware fallback stages activated.

The falsifiable thesis is:

> Behavior-preserving diagnostics and an exact complete-tree replay can
> determine whether any governed 2020 child node exposes multiple physical
> initial DFS cuts or activates a fallback stage that requires separate
> sensitivity instrumentation.

The thesis fails if diagnostics change any governed node assignment or
objective, if any governed tree cannot be regenerated, or if the reported
node universe is incomplete.

## Instrumentation Contract

Retain the three initial DFS counters:

- minimum-deviation oriented candidates;
- minimum-deviation/minimum-cut oriented candidates; and
- distinct unlabeled minimum-deviation/minimum-cut partitions.

Append two booleans to every NRS discovery method:

- `nrs-v0-2-fallback-activated=<true|false>`; and
- `nrs-v0-3-fallback-activated=<true|false>`.

The booleans record entry into each fallback stage, not whether that stage
changed the selected assignment. Candidate generation, refinement, ordering,
and output remain unchanged.

## Frozen Census

- Census year: 2020.
- Universe: all 385 governed recursive split nodes in the 50-State NRS v0.3
  baseline; one-district States contribute zero split nodes.
- Inputs: committed State RCTX files, seed packages, benchmark trees, and
  benchmark node discoveries.
- Replay: rebuild each of the 44 multi-district State packages with its
  published seed package and the instrumented executable.
- Acceptance: exact State assignment preservation and exact per-node canonical
  assignment plus all three objective-component preservation.
- Failures remain in the ledger and no State or node may be replaced.

The package reports node path, seat ratio, unit count, the three initial DFS
counts, both fallback activation booleans, and behavior preservation.

## Decision Rule

- Any node with more than one distinct unlabeled initial DFS partition permits
  a separately precommitted node sensitivity slice.
- Any v0.2 or v0.3 fallback activation requires stage-specific candidate
  instrumentation before seed execution.
- If neither condition occurs, stop broader 2020 DFS/fallback seed expansion
  until a different mechanism-specific thesis is frozen.

## Claim Boundary

This is a governed 2020 complete-tree diagnostic replay. It does not establish
seed-invariant labels or plans, cross-census behavior, national robustness,
optimality, partisan properties, or legal quality.
